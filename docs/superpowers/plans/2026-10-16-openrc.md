# Gentoo z OpenRC — plan implementacji

> **Stan: wykonany** (PR #8, 16.10.2026). Odstępstwa od planu, także od jego ograniczeń (zmiany zachowania Voida, zmiana `omarchy-port-units` przy PipeWire), i ich uzasadnienie: [`wyniki/2026-10-16-openrc.md`](../../../wyniki/2026-10-16-openrc.md). Otwarte sprawy są w Forgejo, nie tutaj.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `port/install.sh` instaluje pełne Omarchy na Gentoo z OpenRC tak, jak dziś na Gentoo z systemd i na Voidzie.

**Architecture:** Shim `systemctl` dzieli się na wspólny front i backend usług initu (runit — kod przeniesiony z dzisiejszego shima, OpenRC — `rc-update`/`rc-service`). Nazwy usług daje mapa `uslugi.tsv` z kolumną na każdy init. Sesja, nadzorca unitów użytkownika i pozostałe shimy idą bez zmian, jak na Voidzie. Na OpenRC lista pakietów nie ma `uwsm`, a ma `elogind` i `chrony`. Warstwa kładzie sesję portu, pliki PipeWire i pilnuje `systemd-tmpfiles-setup`.

**Tech Stack:** bash, OpenRC 0.63+ (Gentoo `23.0/desktop`), elogind, runit (Void), QEMU/podman (VM w `prototyp/vm/`), shellcheck 0.10.

**Spec:** `docs/superpowers/specs/2026-10-15-openrc-design.md`

## Global Constraints

- Obsługiwane pary: `void/runit`, `gentoo/systemd`, `gentoo/openrc`.
- Shimy w `/usr/local/bin` powstają tylko wtedy, gdy oryginału nie ma. Jedyny wyjątek: `uwsm` i `uwsm-app` na initach bez systemd zostają zawsze.
- Zachowanie Voida bez zmian. Dwie świadome różnice: `systemctl status` na runit pisze „, disabled” według `is-enabled`, a nie według samego pliku `down`, a komunikat o usłudze, która nie wstała po `enable --now`, podaje nazwę runit zamiast nazwy unitu.
- Komentarze i komunikaty po polsku, z diakrytykami, w stylu reszty repo.
- `shellcheck -S warning -x -P SCRIPTDIR` czysto na każdym zmienionym pliku (poza `port/bin/omarchy-port-units`, który ma ostrzeżenia z `main` i nie jest zmieniany).
- Każda integracja sprawdzona w VM przez realny kanał. Przy każdym teście shima: zepsuty most (brak backendu albo backend złego initu) musi dać czerwony test.
- Najwyżej jedna VM naraz: host ma ~17 GB wolnego RAM-u, VM bierze 8 GB.
- Pliki przywracaj odwrotnym Editem albo `git show HEAD:<plik> > <plik>`, nigdy `git checkout <plik>`.
- Praca w worktree `/home/szoniu/dev/omarchy-port-openrc`, gałąź `openrc`. Commity `OpenRC (#5): …` z linią `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- VM: katalog `~/vm/omarchy-port` (dalej `$VM_DIR`), SSH `ssh -F $VM_DIR/ssh_config vm`, hasło kont VM w `$VM_DIR/haslo-vm` (poza repo).

## Review Focus

1. **Prawdziwy `uwsm` obecny na OpenRC** (zainstalowany ręcznie albo jako zależność) — shim portu i tak zostaje w `/usr/local/bin` i przesłania go w PATH, a warstwa wypisuje UWAGĘ. Test: zadanie 6, krok 9.
2. **Usługa włączona przez admina w innym runlevelu** (np. `uuidd` w `boot`) — `is-enabled` = enabled, `enable` nie dubluje wpisu w `default`, `disable` zdejmuje ją z `boot`. Test: zadanie 3, `uslugi-test.sh`.
3. **Usługa, która padła (`crashed`)** — `is-active` = inactive (rc 3), `restart` ją podnosi. Test: zadanie 3, `uslugi-test.sh`.
4. **`/etc/conf.d/display-manager` z innym `DISPLAYMANAGER`** (domyślnie `xdm`) — po `systemctl enable sddm.service` jest dokładnie jedna linia `DISPLAYMANAGER="sddm"`. Test: zadanie 6, `uslugi-test.sh` po instalacji.
5. **Wywołanie bez roota z ubogim PATH** (sesja: `systemctl is-active` bez sudo, PATH bez `/sbin`) — poprawny stan usługi. Test: zadanie 2/3, `uslugi-test.sh` (`nobody`, `PATH=/usr/bin:/bin`).

- [x] **Step 1: Test usług — `prototyp/test/uslugi-test.sh`**

```bash
#!/usr/bin/env bash
# Test shima systemctl dla usług systemowych (backend runit albo OpenRC) — jako root, w VM, na działającym
# systemie. Sesja niepotrzebna, więc test idzie też na bazie przed instalacją portu (shim, mapa i backend
# położone ręcznie). Stan sprawdzany WPROST w initcie (runit: /var/service i pliki down; OpenRC:
# /etc/runlevels i rc-service), nie przez shim — to shim jest tu testowany.
# Usługa testowa: uuidd (util-linux — jest na Voidzie i na Gentoo, nic od niej nie zależy).
#   prototyp/test/uslugi-test.sh      → OK/FAIL na wiersz, kod 1 przy jakimkolwiek FAIL
set -uo pipefail
(( EUID == 0 )) || { echo "uslugi-test.sh: uruchom jako root" >&2; exit 2; }
export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
[[ $(command -v systemctl) == /usr/local/bin/systemctl ]] ||
  { echo "uslugi-test.sh: systemctl to nie shim portu ($(command -v systemctl)) — test dotyczy initów bez systemd" >&2; exit 2; }
FAIL=0
ok() { printf '  %-4s %s\n' "$1" "$2"; }
t() { if eval "$2"; then ok OK "$1"; else ok FAIL "$1"; FAIL=$((FAIL + 1)); fi; }
if [[ -d /run/openrc ]]; then
  INIT=openrc
  wlaczona() { [[ -L /etc/runlevels/${2:-default}/$1 ]]; }
  gdziekolwiek() { [[ -n $(compgen -G "/etc/runlevels/*/$1") ]]; }
  dziala() { [[ $(rc-service "$1" status 2>/dev/null) == *'status: started'* ]]; }
  PRZERWA=1   # rc-service działa synchronicznie
else
  INIT=runit
  wlaczona() { [[ -L /var/service/$1 && ! -e /etc/sv/$1/down ]]; }
  gdziekolwiek() { [[ -L /var/service/$1 ]]; }
  dziala() { [[ $(sv status "/var/service/$1" 2>/dev/null) == run:* ]]; }
  PRZERWA=6   # runsvdir skanuje /var/service co ~5 s
fi
echo "### init: $INIT"

echo "### stan wyjściowy: uuidd wyłączony i zatrzymany"
systemctl disable --now uuidd.service >/dev/null 2>&1; sleep "$PRZERWA"
t "disable --now: nie ma go w initcie i nie działa" '! gdziekolwiek uuidd && ! dziala uuidd'
out=$(systemctl is-enabled uuidd.service); rc=$?
t "is-enabled wyłączonej: disabled, rc 1" '[[ $out == disabled && $rc == 1 ]]'
out=$(systemctl is-active uuidd.service); rc=$?
t "is-active zatrzymanej: inactive, rc 3" '[[ $out == inactive && $rc == 3 ]]'

echo "### enable bez --now"
systemctl enable uuidd.service; sleep "$PRZERWA"
if [[ $INIT == openrc ]]; then
  t "OpenRC: włączona (default) i NIE uruchomiona — jak w systemd" 'wlaczona uuidd && ! dziala uuidd'
else
  t "runit: włączona i uruchomiona (bez trybu instalacji runit startuje od razu)" 'wlaczona uuidd && dziala uuidd'
fi
t "is-enabled: enabled" '[[ $(systemctl is-enabled uuidd.service) == enabled ]]'

echo "### tryb instalacji (OMARCHY_PORT_INSTALL): włączona od następnego startu"
systemctl disable --now uuidd.service >/dev/null; sleep "$PRZERWA"
OMARCHY_PORT_INSTALL=1 systemctl enable uuidd.service; sleep "$PRZERWA"
t "is-enabled: enabled" '[[ $(systemctl is-enabled uuidd.service) == enabled ]]'
t "nie uruchomiona do restartu" '! dziala uuidd'
systemctl disable uuidd.service >/dev/null   # runit: zdejmuje też wpis z listy start-at-boot

echo "### enable --now, disable bez --now, stop/start/restart"
systemctl enable --now uuidd.service
t "enable --now: działa od razu" 'dziala uuidd'
t "is-active: active" '[[ $(systemctl is-active uuidd.service) == active ]]'
systemctl disable uuidd.service; sleep "$PRZERWA"
t "disable bez --now: wyłączona, dalej działa" '! wlaczona uuidd && dziala uuidd'
systemctl stop uuidd.service; sleep 1
t "stop: nie działa" '! dziala uuidd'
systemctl start uuidd.service
t "start (usługa wyłączona): działa" 'dziala uuidd'
systemctl restart uuidd.service
t "restart: działa" 'dziala uuidd'

if [[ $INIT == openrc ]]; then
  echo "### OpenRC: usługa w innym runlevelu (admin dodał ją do boot)"
  systemctl disable --now uuidd.service >/dev/null
  rc-update add uuidd boot >/dev/null
  t "is-enabled: enabled (runlevel boot)" '[[ $(systemctl is-enabled uuidd.service) == enabled ]]'
  systemctl enable uuidd.service
  t "enable nie dubluje wpisu w default" 'wlaczona uuidd boot && ! wlaczona uuidd default'
  systemctl disable uuidd.service
  t "disable zdejmuje z boot" '! gdziekolwiek uuidd'

  echo "### OpenRC: usługa padła (crashed)"
  systemctl start uuidd.service
  kill -9 "$(pgrep -x uuidd)"; sleep 1
  t "rc-service widzi crashed" '[[ $(rc-service uuidd status 2>/dev/null) == *crashed* ]]'
  out=$(systemctl is-active uuidd.service); rc=$?
  t "is-active po padnięciu: inactive, rc 3" '[[ $out == inactive && $rc == 3 ]]'
  systemctl restart uuidd.service
  t "restart podnosi usługę po padnięciu" 'dziala uuidd'
  systemctl stop uuidd.service

  echo "### OpenRC: runlevel z mapy (elogind@boot)"
  if [[ -x /etc/init.d/elogind ]]; then
    systemctl enable elogind.service
    t "elogind w boot, nie w default" 'wlaczona elogind boot && ! wlaczona elogind default'
  else
    ok -- "brak /etc/init.d/elogind — pominięte"
  fi

  echo "### OpenRC: sddm → display-manager + DISPLAYMANAGER"
  if [[ -x /etc/init.d/display-manager ]]; then
    cp -p /etc/conf.d/display-manager /etc/conf.d/display-manager.uslugi-test
    sed -i 's/^DISPLAYMANAGER=.*/DISPLAYMANAGER="xdm"/' /etc/conf.d/display-manager
    systemctl enable sddm.service
    t "display-manager w default" 'wlaczona display-manager'
    t "jedna linia DISPLAYMANAGER=\"sddm\" (było xdm)" '[[ $(grep -c "^DISPLAYMANAGER=" /etc/conf.d/display-manager) == 1 ]] && grep -qx "DISPLAYMANAGER=\"sddm\"" /etc/conf.d/display-manager'
    mv -f /etc/conf.d/display-manager.uslugi-test /etc/conf.d/display-manager
  else
    ok -- "brak /etc/init.d/display-manager (baza przed instalacją portu) — pominięte"
  fi
fi

echo "### usługa bez pakietu, pominięta, mapa nazw"
systemctl enable supergfxd.service 2>/dev/null; rc=$?
t "supergfxd (brak pakietu): rc 5, bez wpisu w initcie" '[[ $rc == 5 ]] && ! gdziekolwiek supergfxd'
systemctl enable systemd-oomd.service 2>/dev/null; rc=$?
t "systemd-oomd (- w mapie): rc 0" '[[ $rc == 0 ]]'
out=$(systemctl is-active systemd-oomd.service); rc=$?
t "is-active pominiętej: inactive, rc 3" '[[ $out == inactive && $rc == 3 ]]'
if [[ -e /etc/sv/chronyd || -x /etc/init.d/chronyd ]]; then
  t "status systemd-timesyncd → chronyd" '[[ $(systemctl status systemd-timesyncd.service) == *"(chronyd)"* ]]'
else
  ok -- "brak chronyd (baza przed instalacją portu) — mapa nazw pominięta"
fi

echo "### bez roota, ubogi PATH (jak systemctl is-active w sesji)"
t "is-active sshd jako nobody z PATH=/usr/bin:/bin" '[[ $(su -s /bin/sh nobody -c "env -i PATH=/usr/bin:/bin /usr/local/bin/systemctl is-active sshd.service" 2>/dev/null) == active ]]'

if [[ -x /usr/local/bin/systemd-run ]]; then
  echo "### timery roota (systemd-run --on-active)"
  systemd-run --on-active=60s --unit=omarchy-uslugi-test true
  t "is-active timera: active" '[[ $(systemctl is-active omarchy-uslugi-test.timer) == active ]]'
  systemctl stop omarchy-uslugi-test.timer
  t "po stop: inactive" '[[ $(systemctl is-active omarchy-uslugi-test.timer) == inactive ]]'
fi

systemctl disable --now uuidd.service >/dev/null 2>&1
echo "FAIL: $FAIL"
(( FAIL == 0 ))
```

```bash
# shellcheck shell=bash
# shellcheck disable=SC2034  # USL_KOLUMNA czyta front
# omarchy-port: backend usług runit (Void) dla shima systemctl (port/bin/systemctl) — front sourcuje go
# z /usr/share/omarchy-port/uslugi-backend.sh (kładzie go install-layer.sh). Front robi mapę nazw, kody
# wyjścia i komunikaty systemd i daje tu log oraz MAP; tu jest tylko mechanika runit.
USL_KOLUMNA=runit
SVDIR=/etc/sv
RUNSVDIR=/var/service
# Tryb instalacji (OMARCHY_PORT_INSTALL=1, ustawia go port/install.sh): `enable` bez --now NIE startuje
# usługi — jak w systemd, a Omarchy na tym polega („Enable services only… don't start daemons
# mid-install”). runit nie ma stanu „włączona od następnego startu”, więc: link + plik down + wpis tu;
# core-service 91-omarchy-port-start-at-boot.sh zdejmuje down przed startem usług.
START_AT_BOOT=/var/lib/omarchy-port/start-at-boot
pending() { [[ -f $START_AT_BOOT ]] && /usr/bin/grep -qxF -- "$1" "$START_AT_BOOT"; }
unpend() { [[ -f $START_AT_BOOT ]] && sed -i "/^${1//./\\.}\$/d" "$START_AT_BOOT"; return 0; }
# runsvdir skanuje /var/service co ~5 s — czekamy na supervise/ zamiast zakładać, że już jest
wait_supervised() { local _; for _ in $(seq 1 30); do [[ -e $RUNSVDIR/$1/supervise/stat ]] && return 0; sleep 0.5; done; return 1; }
wait_state() { local _; for _ in $(seq 1 30); do [[ $(usl_stan "$1") == "$2" ]] && return 0; sleep 0.5; done; return 1; }

usl_istnieje() { [[ -d $SVDIR/$1 ]]; }

# Stan usługi: root czyta supervise/stat. Użytkownik NIE — supervise/ to symlink do
# /run/runit/supervise.<nazwa> z prawami 0700 (a `sv status` wymaga supervise/ok), więc bez roota
# patrzymy w jawną tablicę procesów: `runsv <nazwa>` ma dziecko-usługę, a przy log/ także logger.
usl_stan() {
  local st r n expect=0
  st=$(awk '{ print $1; exit }' "$RUNSVDIR/$1/supervise/stat" 2>/dev/null)
  [[ -n $st ]] && { echo "$st"; return; }
  r=$(pgrep -fx "runsv $1") || { echo ''; return; }
  n=$(pgrep -P "$r" | wc -l)
  [[ -e $SVDIR/$1/log/run ]] && expect=1
  (( n > expect )) && echo run || echo down
}
usl_wlaczona() { [[ -L $RUNSVDIR/$1 ]] && { [[ ! -e $SVDIR/$1/down ]] || pending "$1"; }; }

# Semantyka systemd na runit:
#   enable         = link w /var/service + brak pliku down (start przy boocie)
#   disable        = plik down (BEZ zatrzymania — tak jak systemd; Omarchy na tym polega:
#                    `disable docker.service` „do not stop running containers”, `disable iwd`)
#   disable --now  = usunięcie linku (zatrzymuje)
#   mask           = usunięcie linku + down
usl_wlacz() { # usl_wlacz <nazwa> <now>
  if [[ -n ${OMARCHY_PORT_INSTALL:-} ]] && (( ! $2 )) && [[ ! -L $RUNSVDIR/$1 ]]; then
    # down PRZED linkiem — runsv nie może zdążyć wystartować usługi
    touch "$SVDIR/$1/down"
    ln -sfn "$SVDIR/$1" "$RUNSVDIR/$1" || return 1
    mkdir -p "${START_AT_BOOT%/*}"
    pending "$1" || echo "$1" >>"$START_AT_BOOT"
    log "instalacja: $1 włączona od następnego startu"
    return 0
  fi
  rm -f "$SVDIR/$1/down"
  ln -sfn "$SVDIR/$1" "$RUNSVDIR/$1" || return 1
  if (( $2 )); then
    wait_supervised "$1" && wait_state "$1" run || { echo "systemctl (omarchy-port): $1 nie wystartował" >&2; return 1; }
  fi
  return 0
}
usl_wylacz() { # usl_wylacz <nazwa> <now>
  unpend "$1"
  if (( $2 )); then rm -f "$RUNSVDIR/$1"; else touch "$SVDIR/$1/down"; fi
}
usl_maskuj() { unpend "$1"; rm -f "$RUNSVDIR/$1"; touch "$SVDIR/$1/down"; }
usl_odmaskuj() { rm -f "$SVDIR/$1/down"; }
# systemd potrafi wystartować usługę wyłączoną — runit potrzebuje nadzorcy, więc link + down
nadzorowana() {
  if [[ ! -L $RUNSVDIR/$1 ]]; then touch "$SVDIR/$1/down"; ln -sfn "$SVDIR/$1" "$RUNSVDIR/$1"; fi
  wait_supervised "$1" || { echo "systemctl (omarchy-port): runsv nie podjął $1" >&2; return 1; }
}
usl_start() { nadzorowana "$1" && sv start "$RUNSVDIR/$1" >/dev/null; }
usl_restart() { nadzorowana "$1" && sv restart "$RUNSVDIR/$1" >/dev/null; }
usl_stop() { [[ ! -L $RUNSVDIR/$1 ]] || sv stop "$RUNSVDIR/$1" >/dev/null; }
usl_przeladuj() { sv hup "$RUNSVDIR/$1" >/dev/null; }
```

```bash
#!/bin/bash
# omarchy-port: `systemctl` dla systemów BEZ systemd (Void/runit, Gentoo/OpenRC). Instalowany TYLKO gdy
# prawdziwego systemctl nie ma — na Gentoo z systemd nie powstaje.
#   zasilanie (reboot/poweroff/suspend/hibernate…) → loginctl (elogind)
#   --user …                                       → omarchy-port-units (nadzorca unitów użytkownika)
#   usługi systemowe                               → backend initu, mapa nazw w uslugi.tsv (kolumna initu)
# Usługa świadomie pominięta („-” w kolumnie initu) → rc 0 + wpis w logu; nieznana → rc 5 jak w systemd.
# Tu jest to, co wspólne: mapa nazw, kody wyjścia i komunikaty systemd, timery. Mechanika initu siedzi
# w backendzie (/usr/share/omarchy-port/uslugi-backend.sh, z port/share/init/<init>-uslugi.sh), który daje:
#   USL_KOLUMNA (kolumna w mapie), usl_istnieje, usl_stan (run|down|crashed|pusty = brak nadzorcy),
#   usl_wlaczona, usl_wlacz/usl_wylacz <nazwa> <now>, usl_maskuj, usl_odmaskuj, usl_start, usl_restart,
#   usl_stop, usl_przeladuj — rc ≠ 0 = błąd (komunikat wypisuje backend).
MAP=/usr/share/omarchy-port/uslugi.tsv
BACKEND=/usr/share/omarchy-port/uslugi-backend.sh
if (( EUID == 0 )); then LOGF=/var/log/omarchy-port/systemctl.log
else LOGF="${XDG_STATE_HOME:-$HOME/.local/state}/omarchy-port/systemctl.log"; fi
log() { mkdir -p "${LOGF%/*}" 2>/dev/null; printf '%s %s\n' "$(date '+%F %T')" "$*" >>"$LOGF" 2>/dev/null; }

user=0 quiet=0 now=0
rest=()
while (($#)); do
  case $1 in
    --user) user=1 ;;
    --system) user=0 ;;
    -q|--quiet) quiet=1 ;;
    --now) now=1 ;;
    *) rest+=("$1") ;;
  esac
  shift
done
set -- "${rest[@]}"

log "$( ((user)) && echo '--user ')$*"

if ((user)); then
  ((now)) && set -- "$1" --now "${@:2}"
  ((quiet)) && set -- "$1" --quiet "${@:2}"
  exec omarchy-port-units "$@"
fi

verb=${1:-}
shift || true
units=()
for a in "$@"; do [[ $a == -* ]] || units+=("$a"); done

case $verb in
  reboot|poweroff|suspend|hibernate|hybrid-sleep|suspend-then-hibernate)
    exec loginctl "$verb" ;;
  halt) exec loginctl poweroff ;;
  daemon-reload|daemon-reexec|reset-failed) exit 0 ;;
esac

if [[ ! -r $BACKEND ]]; then
  echo "systemctl (omarchy-port): brak backendu usług $BACKEND — uruchom port/install-layer.sh" >&2
  log "brak backendu: $verb ${units[*]}"
  exit 1
fi
# shellcheck source=../share/init/runit-uslugi.sh
. "$BACKEND"

# surowy wpis z kolumny initu (chronyd, display-manager, elogind@boot, „-”); pusty = unitu nie ma w mapie
mapa() {
  awk -F'\t' -v s="$1" -v k="$USL_KOLUMNA" '
    NR == 1 { for (i = 1; i <= NF; i++) if ($i == k) c = i; next }
    c && $1 == s { print $c; exit }' "$MAP" 2>/dev/null
}
# nazwa usługi initu dla unitu systemd: z mapy (bez runlevelu po „@”), „-” (pominięty) albo — dla unitu
# spoza mapy — ta sama nazwa, jeśli init ma taką usługę; nic = nieznany
nazwa_uslugi() {
  local u=${1%.service} wpis
  u=${u%.socket}; u=${u%.timer}; u=${u%.path}
  wpis=$(mapa "$u")
  if [[ -n $wpis ]]; then printf '%s\n' "${wpis%%@*}"; return; fi
  usl_istnieje "$u" && printf '%s\n' "$u"
}

need_root() {
  if (( EUID != 0 )); then
    echo "Failed to $verb $1: Access denied (omarchy-port: wymaga roota — użyj sudo)" >&2
    exit 4
  fi
}

# Timery z `sudo systemd-run --on-active` (omarchy-sudo-passwordless): plik „next pid”
TIMERS=/run/omarchy-port/timers

rc=0
for unit in "${units[@]}"; do
  if [[ $unit == *.timer && -z $(nazwa_uslugi "$unit") ]]; then
    t="$TIMERS/${unit%.timer}.timer"; tpid=$(awk '{ print $2 }' "$t" 2>/dev/null)
    case $verb in
      is-active)
        if [[ -n $tpid ]] && kill -0 "$tpid" 2>/dev/null; then ((quiet)) || echo active
        else ((quiet)) || echo inactive; rc=3; fi ;;
      stop)
        need_root "$unit"
        [[ -n $tpid ]] && kill "$tpid" 2>/dev/null; rm -f "$t" ;;
      *) echo "systemctl (omarchy-port): $verb dla timera $unit nieobsługiwane" >&2; rc=1 ;;
    esac
    continue
  fi
  name=$(nazwa_uslugi "$unit")
  if [[ $name == - ]]; then
    case $verb in
      is-active) ((quiet)) || echo inactive; rc=3 ;;
      is-enabled) ((quiet)) || echo disabled; rc=1 ;;
      is-failed) rc=1 ;;
      *) ((quiet)) || echo "omarchy-port: $unit — pominięty na $USL_KOLUMNA (zob. $MAP)" >&2
         log "pominięty: $verb $unit" ;;
    esac
    continue
  fi
  if [[ -z $name ]] || ! usl_istnieje "$name"; then
    # nazwa z mapy bez usługi w initcie = pakietu nie ma — NIE robimy wiszącego wpisu
    case $verb in
      is-active) ((quiet)) || echo inactive; rc=3; continue ;;
      is-enabled) ((quiet)) || echo "Failed to get unit file state for $unit: No such file or directory" >&2; rc=1; continue ;;
      is-failed) rc=1; continue ;;
    esac
    echo "Failed to $verb $unit: Unit file $unit does not exist." >&2
    log "nieznany/brak pakietu: $verb $unit ($USL_KOLUMNA: ${name:-?})"
    rc=5; continue
  fi
  case $verb in
    enable)  need_root "$unit"; usl_wlacz "$name" "$now" || rc=1 ;;
    disable) need_root "$unit"; usl_wylacz "$name" "$now" || rc=1 ;;
    mask)    need_root "$unit"; usl_maskuj "$name" || rc=1 ;;
    unmask)  need_root "$unit"; usl_odmaskuj "$name" || rc=1 ;;
    start)   need_root "$unit"; usl_start "$name" || rc=1 ;;
    restart) need_root "$unit"; usl_restart "$name" || rc=1 ;;
    stop)    need_root "$unit"; usl_stop "$name" || rc=1 ;;
    reload)  need_root "$unit"; usl_przeladuj "$name" || rc=1 ;;
    try-restart|condrestart)
      need_root "$unit"
      if [[ $(usl_stan "$name") == run ]]; then usl_restart "$name" || rc=1; fi ;;
    is-active)
      if [[ $(usl_stan "$name") == run ]]; then ((quiet)) || echo active
      else ((quiet)) || echo inactive; rc=3; fi ;;
    is-enabled)
      if usl_wlaczona "$name"; then ((quiet)) || echo enabled
      else ((quiet)) || echo disabled; rc=1; fi ;;
    is-failed) rc=1 ;;
    status)
      st=$(usl_stan "$name")
      echo "$unit ($name): ${st:-brak nadzorcy}$(usl_wlaczona "$name" || echo ', disabled')"
      [[ $st == run ]] || rc=3 ;;
    *)
      echo "systemctl (omarchy-port): nieobsługiwane: $verb" >&2
      log "nieobsługiwane: $verb $unit"
      exit 1 ;;
  esac
done
exit $rc
```

```bash
# shellcheck shell=bash
# shellcheck disable=SC2034  # USL_KOLUMNA czyta front
# omarchy-port: backend usług OpenRC (Gentoo) dla shima systemctl (port/bin/systemctl) — front sourcuje go
# z /usr/share/omarchy-port/uslugi-backend.sh (kładzie go install-layer.sh). Front robi mapę nazw, kody
# wyjścia i komunikaty systemd i daje tu log oraz MAP; tu jest tylko mechanika OpenRC.
# rc-update add NIE startuje usługi, więc „włączona od następnego startu” (Omarchy: „Enable services only…
# don't start daemons mid-install”) wychodzi sama — bez trybu instalacji, którego potrzebuje runit.
# Pełne ścieżki: Omarchy sprawdza stan usług bez sudo, a w sesji PATH bywa bez /sbin.
USL_KOLUMNA=openrc
RC_SERVICE=/sbin/rc-service
RC_UPDATE=/sbin/rc-update
RUNLEVELS=/etc/runlevels

usl_istnieje() { [[ -x /etc/init.d/$1 ]]; }

# runlevel z mapy (kolumna openrc: elogind@boot), domyślnie default
usl_runlevel() {
  local r
  r=$(awk -F'\t' -v n="$1" '
    NR == 1 { for (i = 1; i <= NF; i++) if ($i == "openrc") c = i; next }
    c && index($c, n "@") == 1 { print substr($c, length(n) + 2); exit }' "$MAP" 2>/dev/null)
  printf '%s\n' "${r:-default}"
}

# Stan z `rc-service <nazwa> status` („* status: started|stopped|crashed|…”). Gdyby bez roota rc-service
# nie odpowiedział, zostaje katalog stanu OpenRC (/run/openrc/started — czytelny dla wszystkich).
usl_stan() {
  local st
  st=$("$RC_SERVICE" "$1" status 2>/dev/null | sed -n 's/.*status: *\([a-z]*\).*/\1/p' | head -1)
  case $st in
    started) echo run ;;
    crashed) echo crashed ;;
    '') if [[ -e /run/openrc/started/$1 ]]; then echo run; else echo down; fi ;;
    *) echo down ;;
  esac
}
# włączona = w którymkolwiek runlevelu (admin mógł dodać usługę do boot zamiast default)
usl_wlaczona() {
  local r
  for r in "$RUNLEVELS"/*/"$1"; do [[ -L $r ]] && return 0; done
  return 1
}

# SDDM na OpenRC nie ma własnego skryptu: wstaje przez display-manager (gui-libs/display-manager-init,
# dociągany przez sddm[-systemd]) z DISPLAYMANAGER w /etc/conf.d/display-manager (domyślnie xdm).
# Omarchy włącza sddm.service, a mapa kieruje to na display-manager — innego menedżera port nie włącza.
dm_sddm() {
  local f=/etc/conf.d/display-manager
  if [[ -f $f ]] && grep -q '^DISPLAYMANAGER=' "$f"; then
    sed -i 's/^DISPLAYMANAGER=.*/DISPLAYMANAGER="sddm"/' "$f"
  else
    echo 'DISPLAYMANAGER="sddm"' >>"$f"
  fi
}

usl_wlacz() { # usl_wlacz <nazwa> <now>
  if ! usl_wlaczona "$1"; then
    "$RC_UPDATE" add "$1" "$(usl_runlevel "$1")" >/dev/null || return 1
  fi
  if [[ $1 == display-manager ]]; then dm_sddm || return 1; fi
  if (( $2 )); then usl_start "$1" || return 1; fi
  return 0
}
# disable = zdjęcie z każdego runlevelu, bez zatrzymania — jak w systemd; --now dodatkowo zatrzymuje
usl_wylacz() { # usl_wylacz <nazwa> <now>
  local r
  for r in "$RUNLEVELS"/*/"$1"; do
    [[ -L $r ]] || continue
    "$RC_UPDATE" del "$1" "$(basename "$(dirname "$r")")" >/dev/null || return 1
  done
  if (( $2 )); then usl_stop "$1" || return 1; fi
  return 0
}
# OpenRC nie ma maski: mask = disable bez zatrzymania (jak systemctl mask), unmask nic nie robi
usl_maskuj() { usl_wylacz "$1" 0; }
usl_odmaskuj() { :; }
# Usługa „crashed” jest dla OpenRC wciąż uruchomiona: start mówi „already started”, więc najpierw zap
usl_start() {
  case $(usl_stan "$1") in
    run) return 0 ;;
    crashed) "$RC_SERVICE" "$1" zap >/dev/null ;;
  esac
  "$RC_SERVICE" "$1" start >/dev/null
}
usl_restart() {
  if [[ $(usl_stan "$1") == crashed ]]; then "$RC_SERVICE" "$1" zap >/dev/null; fi
  "$RC_SERVICE" "$1" restart >/dev/null
}
usl_stop() { [[ $(usl_stan "$1") == down ]] || "$RC_SERVICE" "$1" stop >/dev/null; }
usl_przeladuj() { "$RC_SERVICE" "$1" reload >/dev/null; }
```
